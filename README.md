# WordForge

WordForge is a WPF rebuild of the original WordForge application. It uses only internal controls and adopts an EchoForge-style layout.

## Build

Requires the .NET 9 SDK. Open `WordForge.sln` in Visual Studio and press **F5** to build and run.
